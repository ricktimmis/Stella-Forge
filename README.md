# Stella Forge: Open Concept for In-Orbit Vacuum Metal Additive Manufacturing

Version 0.1 Concept White Paper - October 2026
Status: Concept / Open Source (Apache 2.0)

## Executive Summary
Stella Forge proposes a practical path toward in-orbit metal additive manufacturing focused on curved (spherical and elliptical) structures. The system utilizes a wire-only feedstock, a resistive-laser hybrid energy source, and a conformal print head that maintains thermal contact with the workpiece for controlled deposition in hard vacuum.

## Core Innovations
- **Thermal Integration:** Novel implementation of a closed-loop thermal system on the print head to recover heat from the cooler zone and transfer it to the pre-heater zone, drastically improving power efficiency in orbit.
- **Constraint Focus:** System is deliberately limited to spherical and elliptical geometries to manage initial complexity and allow for targeted validation.
